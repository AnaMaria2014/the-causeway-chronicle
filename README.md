# The Causeway Chronicle | Vintage Northern Ireland Travel Journal

A vintage-inspired editorial travel website celebrating the hidden beauty, folklore, landscapes and legendary destinations of Northern Ireland.

## Live Demo
https://the-causeway-chronicle.netlify.app/

## Overview
The Causeway Chronicle was designed as an immersive digital travel journal with a warm, heritage-inspired aesthetic.

Blending storytelling, folklore, user-submitted travel notes and editorial design, this project showcases Northern Ireland’s most captivating places through a magazine-style experience.

## Features
- Fully responsive multipage website
- Vintage editorial / newspaper-inspired design
- Custom heritage-inspired branding
- Interactive homepage with featured destinations
- Search and category filters
- Dedicated destination article pages
- Community travel stories
- User story submission form
- Scroll reveal animations
- Elegant typography and journal-style layout
- Personalized photography integration
- Internal navigation between travel articles

## Featured Destinations
- Giant’s Causeway
- The Dark Hedges
- Glenariff Forest
- Ballintoy Harbour
- Mussenden Temple
